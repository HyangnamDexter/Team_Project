# 척추 X-ray 영상처리 알고리즘 파라미터 비교 실험 (`core/algorithms.py`)

> **문서 목적**: 3주차 C 담당 3단계 알고리즘 비교 실험 보고서. `qc_thresholds.md`에서 선정한 VinDr-SpineXR 대표 척추 X-ray 5종(정상·흐림·어두움·밝음·임플란트)을 대상으로 `core/algorithms.py`의 3종 알고리즘(`apply_clahe`, `apply_denoise`, `apply_edge`)을 파라미터별로 실행하고 정량 지표와 권장 기본값을 도출한다.

---

## 1. 실험 조건 및 기준 영상 (대표 5종)

- **입력 파이프라인**: `core.dicom_io.load_dicom()` → `core.dicom_io.apply_window(pixels)` (`uint8` 2D 원본 해상도)
- **실행 환경**: 로컬 CPU (Apple Silicon), OpenCV 5.1.0, `core/algorithms.py` 원본 함수 직접 호출 (`sobel ksize=5` 비교 항목만 동일 Sobel 크기 정규화 수식으로 병행 측정)
- **보조 정량 지표 정의**:
  - **밝기(`B`) / 대비(`C`) / 선명도(`S`)**: `core.quality.image_quality()` 기준 (`mean`, `std`, `Laplacian.var()`)
  - **고주파 잡음 추정치($\hat{\sigma}_{\text{noise}}$)**: Immerkaer(1996) 3×3 Laplacian 커널 기반 영상 노이즈 표준편차 추정치 (낮을수록 평탄부 잡음 감소)
  - **평균 경사 강도(`grad_mean`)**: 3×3 Sobel 경사 크기 평균 (Denoise 전후 비율인 **경사 보존율**로 에지 흐림 억제 정도를 측정)

## 2. 실험 1: `apply_clahe` (국소 대비 향상)

### 2.2 대표 유형별 CLAHE 효과 비교 (`tile_size=8` 기준)
| 유형 | 원본 (`B` / `S` / `noise`) | `clip=1.0, tile=8` | **`clip=2.0, tile=8` (권장)** | `clip=4.0, tile=8` |
| :--- | :---: | :---: | :---: | :---: |
| **흐림** | 67.30 / **15.32** / 0.467 | 73.89 / 36.66 (미달) / 0.737 | 78.06 / **65.28 (QC 통과)** / 0.977 | 82.21 / 126.17 / 1.323 |
| **어두움** | **30.46** / 85.92 / 0.880 | 36.21 / 168.20 / 1.305 | **40.85 (QC 통과)** / 270.78 / 1.689 | 48.79 / 430.28 / 2.216 |
| **밝음** | 178.73 / 223.65 / 1.262 | 164.21 / 539.14 / 2.116 | **152.28** / 1022.39 / 2.969 | 136.30 / 2298.43 / **4.490 (과증폭)** |
| **임플란트** | 99.17 / 173.66 / 1.107 | 102.80 / 250.65 / 1.765 | 105.49 / **361.54** / 2.383 | 109.20 / 612.68 / **3.318 (배경 과립)** |

- **분석**:
  - `clip_limit=1.0`은 흐림 영상(`S=36.66`)의 윤곽 개선이 부족하다.
  - `clip_limit=2.0, tile_size=8`은 **흐림(`15.32 → 65.28`)과 어두움(`30.46 → 40.85`) 영상을 모두 QC 통과 수준으로 개선**하고, 밝은 영상의 과휘도(`178.73 → 152.28`)를 완화하며, 처리 시간도 `2.47 ms`로 가장 빠르다.
  - `clip_limit=4.0` 또는 `tile_size=16`은 선명도 수치만 과도하게 오르며 평탄부 잡음($\hat{\sigma}_{\text{noise}}$ 최대 `3.477`, 밝음 영상 `4.703`)과 금속 주변 헤일로(halo)가 심해진다.

## 3. 실험 2: `apply_denoise` (노이즈 제거·평활화)

`method ∈ {"gaussian", "median", "bilateral"}` × `ksize ∈ {3, 5, 7}` 총 9조합에 대해 노이즈 억제와 에지/선명도 보존 트레이드오프를 측정하였다. (`bilateral`은 `core/algorithms.py` 구현대로 `sigmaColor=75, sigmaSpace=75, d=ksize` 기준)

### 3.1 5종 평균 정량 비교 표
| `method` | `ksize` | 평균 선명도(`S`) | 선명도 보존율 | 에지 경사 보존율 | 잡음($\hat{\sigma}_{\text{noise}}$) | 잡음 억제율 | PSNR (dB) | 평균 처리 시간 (ms) |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| 원본 | — | 130.95 | 100.0% | 100.0% | 1.064 | 0.0% | ∞ | — |
| `gaussian` | 3 | 8.13 | 7.9% | 70.7% | 0.249 | 74.8% | 41.59 | 0.94 |
| `gaussian` | 5 | 3.56 | 4.0% | 59.8% | 0.207 | 78.7% | 40.10 | **0.33** |
| `gaussian` | 7 | 1.96 | 2.6% | 50.7% | 0.191 | **80.4%** | 39.02 | 0.47 |
| `median` | 3 | **54.00** | **37.5%** | 67.5% | 0.430 | 59.5% | 41.30 | 0.92 |
| `median` | 5 | 41.50 | 28.7% | 52.3% | 0.287 | 72.3% | 40.60 | 0.88 |
| `median` | 7 | 37.04 | 25.7% | 45.0% | 0.235 | 76.9% | 39.31 | 2.18 |

| `bilateral` | 7 | 26.85 | 17.3% | 47.5% | 0.214 | 78.5% | 39.76 | 7.90 |

### 3.2 핵심 유형별 흐림 억제 vs 노이즈 제거 비교 (`ksize=3` vs `ksize=5`)
| 방식 (`method`, `ksize`) | 흐림 (`S` / 경사보존 / PSNR) | 어두움 (`S` / 경사보존 / 잡음억제) | 임플란트 (`S` / 선명도보존 / 경사보존 / PSNR) |
| :--- | :---: | :---: | :---: |
| `gaussian`, `k=3` | 2.25 / 79.4% / 49.72 dB | 4.68 / 51.8% / 76.6% | 11.50 / 6.6% / 72.0% / 38.30 dB |
| `gaussian`, `k=5` | 1.46 / 70.1% / 47.81 dB | 1.75 / 39.0% / 84.9% | 4.24 / 2.4% / 61.4% / 36.69 dB |
| `median`, `k=3` | 5.14 / 76.8% / 49.03 dB | 11.82 / 48.1% / 74.3% | **126.93 / 73.1%** / 69.8% / 43.51 dB |
| `median`, `k=5` | 3.56 / 61.0% / 46.52 dB | 7.52 / 37.0% / 82.4% | 122.47 / 70.5% / 55.2% / 42.11 dB |
| **`bilateral`, `k=3`** | 3.32 / **81.8%** / **50.16 dB** | **12.37 / 58.3%** / 53.6% | 112.80 / 65.0% / **75.9% / 44.29 dB** |
| `bilateral`, `k=5` | 1.71 / 68.2% / 47.24 dB | 3.70 / 37.8% / 74.9% | 100.54 / 57.9% / 60.7% / 41.81 dB |

- **분석**:
  - **`gaussian`**은 잡음 억제율(74.8~80.4%)과 속도(0.33~0.94 ms)가 가장 우수하지만, **임플란트 선명도 보존율이 `k=3`에서 6.6%, `k=5`에서 2.4%로 급락**해 척추 피질골·나사산 경계를 과도하게 흐린다.
  - **`bilateral (k=3)`**은 **5종 평균 에지 경사 보존율 74.5%(1위), PSNR 43.39 dB(1위)**로 흐림·어두움·임플란트 전 유형에서 골격·금속 경계를 가장 잘 보존하면서 잡음을 57.4% 줄인다(`2.13 ms`).
  - **`median (k=3)`**은 `0.92 ms`의 빠른 속도와 함께 임플란트 금속 경계 선명도 보존율 **73.1%**를 기록해 점 잡음 제거 대안으로 우수하다. `ksize=7` 이상은 모든 방식에서 경사 보존율이 50% 미만으로 떨어져 척추 X-ray 미세 구조 판독에 부적합하다.

## 4. 실험 3: `apply_edge` (경계·영역 추출)

`canny` 3조합(`(30, 90)`, `(50, 150)`, `(80, 200)`), `sobel` (`ksize=3` 현행 구현 vs `ksize=5` 비교 실험), `otsu` 결과를 비교하였다.

> **구현 참고**: `core/algorithms.py`의 `apply_edge(..., method="sobel")`은 현재 `ksize=3`으로 고정되어 있으며, `ksize=5`는 커널 크기 비교를 위해 동일한 Sobel 크기 정규화 수식으로 별도 계측하였다.

### 4.1 5종 유형별 엣지/전경 픽셀 비율 및 처리 시간 비교 표

| 방식 및 파라미터 | 지표 | 정상 | 흐림 | 어두움 | 밝음 | 임플란트 | 평균 처리 시간 (ms) |
| :--- | :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| `canny (30, 90)` | 엣지 비율 (%) / 파편 수 | 14.150% (16,117) | 0.158% (199) | 2.812% (4,691) | 4.175% (3,537) | 0.520% (199) | 5.45 |
| **`canny (50, 150)` (권장)** | 엣지 비율 (%) / 파편 수 | **2.627%** (2,932) | 0.029% (18) | **0.586%** (754) | 0.063% (82) | **0.134%** (14) | **2.69** |
| `canny (80, 200)` | 엣지 비율 (%) / 파편 수 | 0.553% (740) | 0.020% (9) | 0.078% (80) | 0.012% (9) | 0.106% (2) | 1.56 |
| **`sobel (ksize=3)` (권장)** | 평균강도 / 강한엣지(`≥30`) | 5.48 / **0.640%** | 2.40 / 0.054% | 4.87 / 1.742% | 13.94 / 8.581% | 2.45 / **0.104%** | 25.67 |
| `sobel (ksize=5)` (비교) | 평균강도 / 강한엣지(`≥30`) | 5.81 / 1.283% | 2.60 / 0.122% | 4.79 / 3.438% | 11.06 / 4.125% | 3.65 / 0.276% | 18.85 |
| `otsu` (자동 이진화) | 자동 임계값(`T`) / 전경(%) | `T=106` / 44.37% | `T=90` / 33.98% | `T=89` / 11.71% | `T=119` / 82.18% | `T=106` / 44.71% | 2.46 |

- **분석**:
  - **`canny`**: `(30, 90)`은 정상 영상에서 엣지가 `14.15%`(파편 16,117개)까지 폭발해 노이즈 윤곽이 과다하다. `(80, 200)`은 정상(`0.55%`)·밝음(`0.012%`) 영상에서 해부학적 골격 경계까지 대부분 소실된다. **`(50, 150)`**은 정상·어두움·임플란트에서 핵심 뼈·금속 윤곽만 깔끔하게 남기며(`2.69 ms`), 흐림·밝음 영상에서는 **`apply_clahe(2.0, 8)` 전처리 후 `canny(50, 150)`**을 적용하거나 `(30, 90)`으로 낮추어 보완하는 것이 효과적이다.
  - **`sobel`**: `ksize=3`은 엣지 폭이 얇고 위치 정밀도가 높다. `ksize=5`는 강한 엣지 비율이 약 2배 늘어나지만 윤곽이 두꺼워져 미세 추체 경계가 뭉개지므로 현행 `ksize=3` 유지가 적합하다. (단, 최대값 정규화 방식이므로 임플란트처럼 극단적 고대비 경계가 있을 때는 일반 뼈 경계 강도가 낮게 표현되는 특성을 감안해야 한다.)
  - **`otsu`**: `2.46 ms`로 빠르며 공기 배경과 신체 영역을 자동 분리(`어두움 11.7%`, `정상 44.4%`, `밝음 82.2%`)하는 **FOV/전경 마스킹 용도**에 적합하다.

## 5. 결론: 척추 X-ray 권장 기본 파라미터 요약

| 알고리즘 | 권장 기본 파라미터 | 현행 `core/algorithms.py` 기본값과의 관계 | 권장 이유 (어두움·흐림·임플란트 중심) |
| :--- | :--- | :--- | :--- |
| **`apply_clahe`** | **`clip_limit=2.0, tile_size=8`** | 동일 (유지 권장) | 어두움(`B: 30.46→40.85`)·흐림(`S: 15.32→65.28`) 모두 QC 통과 수준으로 회복하면서 잡음 과증폭(`clip=4.0`)과 임플란트 halo를 억제 (`2.47 ms`) |
| **`apply_denoise`** | **`method="bilateral", ksize=3`**<br>(대안: `median, ksize=3`) | 현행 기본은 `gaussian, ksize=5`<br>*(척추 X-ray UI 프리셋으로 `bilateral k=3` 권장)* | `gaussian`은 임플란트 선명도 93~98% 손실; `bilateral k=3`은 최고 에지 경사 보존율(`74.5%`)과 최고 PSNR(`43.39 dB`)로 골격·금속 윤곽 보존 (`2.13 ms`). 흐림 영상은 denoise 생략 또는 `k=3` 최소 적용 권장 |
| **`apply_edge`** | **`method="canny", low=50, high=150`**<br>(연속 강도맵: `sobel ksize=3`, 전경분리: `otsu`) | 동일 (유지 권장) | `(30, 90)`의 과다 노이즈와 `(80, 200)`의 골격 소실 사이 최적 균형(`2.69 ms`). 흐림/어두움 영상은 `CLAHE(2.0, 8)` 선행 적용 시 윤곽 추출 안정성 향상 |
