# 촬영 종류별 영상 품질 기준값 산정 근거 (`QC_THRESHOLDS_VERSION = "v2"`)

## 1. 측정 지표 정의 (입력: 8-bit 0~255 윈도우잉 완료 2D 단면)
- **밝기 (`brightness`)**: 전체 픽셀 평균 휘도 ($\mu$)
- **대비 (`contrast`)**: 전체 픽셀 표준편차 ($\sigma$, RMS Contrast)
- **선명도 (`sharpness`)**: 2D Laplacian 필터 응답의 분산 ($\text{Var}(\nabla^2 I)$)

---

## 2. 촬영 종류(Modality)별 임계치 및 버전 변경 이력 (`v1` → `v2`)

| Modality | `brightness_min` | `brightness_max` | `contrast_min` | `sharpness_min` | 임상/영상학적 근거 |
| :--- | :---: | :---: | :---: | :---: | :--- |
| **DX / CR** (X-ray, **v2 확정**) | 35.0 | 220.0 | 25.0 | **30.0** *(v1: 50.0)* | 조사선량 과다(백화)·부족(암화) 검출, 헤더 WL 기준 하위 10%(p10=29.05) 실질 흐림 영상 선별 |
| **CT** *(코드 호환 유지)* | 25.0 | 210.0 | 30.0 | 80.0 | FOV 외부 공기 영역(0 부근)이 포함되어 평균 밝기 하한을 낮추고, 단면 경계 선명도 기준을 상향 |
| **MR** *(코드 호환 유지)* | 30.0 | 215.0 | 22.0 | 40.0 | 연부조직 위주 신호 특성상 대비·경계 기울기가 CT보다 완만하므로 하한을 완화 적용 |

> **v1 → v2 개정 사유**: 실제 앱 뷰어(`pages/2_Viewer.py`)의 기본 표시 경로인 **DICOM 헤더 WL(없으면 자동 윈도우)** 기준으로 VinDr-SpineXR 626장을 실측한 결과, 기존 `v1`의 `DX sharpness_min = 50.0`은 정상 영상의 28.3%(전체 24.3%, 152장)에 과도한 재촬영 경고를 발생시켰다. 헤더 WL 분포(p10 = `29.05`)와 대표 5종 사례 판정을 종합 검증해 **`DX sharpness_min = 30.0` (`QC_THRESHOLDS_VERSION = "v2"`)**으로 확정하고 `core/quality.py` 및 `tests/test_quality.py`에 반영하였다.

## 5. `QC_THRESHOLDS["DX"]` v2 확정 근거 요약

1. **`brightness_min = 35.0`, `brightness_max = 220.0` 유지**: 헤더 WL 기준 광범위 암부 저휘도 이상치(`12dd72dad9...`, `B=24.39`, 전체 2건/0.3%)를 정확히 검출하고, 정상 고휘도 영상(`max=175.07`, 자동 윈도우 `max=202.02`)의 오탐 없이 실제 백화/과노출(`>220`)만 선별한다.
2. **`contrast_min = 25.0` 유지**: 헤더 WL 기준 저대비 이상치 8건(1.3%, `min=17.73`)을 유효하게 검출하며 대표 정상·밝음·임플란트 영상에는 오탐이 없다.
3. **`sharpness_min = 30.0` 확정 (`v1: 50.0 → v2: 30.0`)**:
   - 헤더 WL 분포의 `p10 = 29.05` 직상단에 정렬되어 전체 통과율이 `74.3% → 87.9%`로 정상화되고, 정상 영상의 불필요한 재촬영 경고가 `28.3% → 13.5%`로 절반 이하로 감소한다.
   - 동시에 대표 흐림 영상(`14.25`)은 기준(`30.0`) 대비 충분한 여유(-15.75)로 불합격 판정되고, 대표 정상(`110.16`)·밝음(`207.07`)·임플란트(`131.44`)는 모두 안정적으로 통과한다.
