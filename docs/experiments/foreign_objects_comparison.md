# 고밀도 이물질(금속·임플란트) 검출 방법 비교 실험 및 오검출 사례 정리

> **문서 목적**: 3주차 C 담당 이물질 검출 비교 실험 결과 기록. 동일한 VinDr-SpineXR `test` 122장(임플란트 58장, 정상 64장, 정답 박스 96개)을 기준으로 OpenCV 규칙 기반 방식(기본 / 국소 대비 / 개선 실험)과 YOLO11n 딥러닝 탐지 모델(`val` 최고 F1 기준 선정·고정 `conf=0.40`)의 정량 성능·처리 속도·오검출(FP)/미검출(FN) 사례 및 ONNX 변환 검증 결과를 비교 정리한다.  
> ⚠️ 본 실험 결과는 교육 및 영상 품질 점검(고밀도 이물질 의심 영역 표시·재촬영 요청 보조) 목적이며 실제 의료 진단 용도가 아니다.

## 1. 실험 조건, 데이터셋 구성 및 재현 방법

### 1.1 평가 데이터셋 (`test` 분할 — YOLO11n 평가와 100% 동일 목록)
- **출처**: VinDr-SpineXR `test` 분할 (`scripts/prepare_spinexr.py` 생성, `seed=42`, `normal_per_implant=1.0`)
- **계획 vs 최종 변환 차이 (16장 제외 원인)**: 전체 계획 642장(`test` 128장) 중 16장(`train` 정상 8장, `val` 정상 2장, `test` 임플란트 6장)이 변환에서 제외되어 최종 626장(`train 404 / val 100 / test 122`)을 사용하였다. 제외된 16장 모두 로컬 원본 `.dicom` 파일과 JPEG 2000 픽셀 디코딩은 정상이나, **`WindowCenter`·`WindowWidth` 태그 문자열 말미에 비표준 쉼표(`,`, 예: `'44394,'`)**가 포함되어 `core.dicom_io.load_dicom()` 내부 `float()` 변환 시 `ValueError`가 발생해 `InvalidDicomError`로 제외된 것으로 확인되었다.
- **`test` 122장 구성**:
  - 양성(Surgical implant 포함): **58장** (정답 박스 총 **96개**, 다중 박스 영상 20/58장)
  - 정상(No finding, 정답 박스 0개): **64장**
  - 원본 DICOM 해상도: 세로 1,148~3,935(중앙값 2,874) × 가로 831~3,899(중앙값 1,243) px, `MONOCHROME2` 118장 / `MONOCHROME1` 4장(`load_dicom` 자동 반전)
  - 정답(GT) 박스 면적 비율: 중앙값 **3.58%**, 평균 **5.74%**, `max_area_ratio=0.02` 초과 **63/96개(65.6%)**, `0.5%` 미만 소형 **21/96개(21.9%)**, 중첩 내부 GT **10/58장·19/96개(19.8%)**

### 1.3 평가 지표, 1:1 매칭 순서 및 중복 처리 규칙
1. **엄격 매칭 (`IoU ≥ 0.50`, 1:1 매칭)**:
   - **YOLO11n**: 예측 박스를 `confidence` 내림차순 정렬 후 1:1 greedy 매칭.
   - **OpenCV**: confidence가 없으므로 각 연결 요소의 원시 평균 밝기(`mean`) 내림차순 정렬 후, 최대 IoU GT가 `IoU ≥ 0.50`이고 미매칭이면 1:1 `TP`로 할당. 동일 GT에 중복 적중한 추가 박스는 모두 `FP`로 집계.
2. **완화 매칭 (`IoU > 0`, 1:1 및 `Center-in-GT`, 1:1)**:
   - OpenCV는 임플란트 조립체 1개를 여러 나사·로드 조각으로 분할 검출하므로 `IoU ≥ 0.50` 달성이 구조적으로 어렵다. 위치 포착 여부를 확인하기 위해 조건(`IoU > 0` 또는 예측 중심이 GT 내부 포함)을 만족하는 모든 `(pred, gt)` 쌍을 `IoU` 내림차순 정렬해 1:1 greedy 매칭하였다(중복 적중 파편은 여전히 `FP`).
3. **참고 지표 (`IoU > 0`, 다대일·파편 허용)**: 1개 GT에 여러 OpenCV 조각이 적중한 경우 중복 파편에 FP 벌점을 주지 않고 GT 적중률(`Recall`)과 GT 적중 예측 비율(`Precision`)을 병기하였다.
4. **처리 시간**: OpenCV는 순수 검출 알고리즘 실행 시간(`time.perf_counter`)만 측정하였다. (원본 DICOM 로딩 평균 `0.2303초/장` 별도)

### 2.4 정량 비교 핵심 해석
1. **OpenCV에서 `IoU ≥ 0.50` TP가 0~1건에 그친 구조적 원인**: 정답 박스 96개 중 63개(65.6%)가 `max_area_ratio=0.02`를 초과하는 대형 조립체(나사+로드 전체) 라벨인 반면, OpenCV는 임플란트 1개를 평균 ~13개의 개별 부품 조각(`bg_sigma=25.0`: GT 내부 적중 1,098개 / 적중 GT 84개)으로 분할 검출하여 GT당 최대 IoU 중앙값이 `0.0135`(최대 `0.5011`)에 그친다.
2. **국소 대비(`bg_sigma=25.0`) + 5% 경계 제외 효과**: `bg_sigma=25.0`은 `IoU > 0` 재현율을 **45.83% → 86.46%(+40.6%p)**로 크게 끌어올렸고, 5% 경계 필터 결합 시 GT 적중 손실 0건(`1,098 → 1,098`)으로 오검출만 **894건(-17.4%, 정상 -20.1%)** 절감했다.
3. **백분위 방식의 근본 한계 (`normal FPR = 100%`) vs YOLO11n (`3.12%`)**: OpenCV `percentile=99.5`는 정상 영상에서도 무조건 상위 0.5%를 추출해 `normal FPR = 100%`가 되지만, YOLO11n(`conf=0.40` 고정)은 정상 오탐률을 **3.12% (2/64장)**, 영상당 오검출을 **0.1803개**(OpenCV 개선 A 대비 **1/193 수준**)로 낮추면서 엄격 `IoU ≥ 0.50`에서 `Precision = 0.6944`, `F1 = 0.5952`, `mAP@0.5 = 0.6527`을 달성했다.

#### (2) 정량 집계 사실 및 오류 추정 원인 (`conf=0.40` 고정 기준)
- **정량 확인된 사실**:
  - 최종 고정 기준(`conf=0.40`)에서 전체 FP 22건 중 **정상 영상 오탐은 2건(2/64장, `normal FPR = 3.12%`)**, **임플란트 양성 영상 내부 FP는 20건(전체 FP의 90.9%, `FP/implant = 0.3448`)**이다.
  - 정상 오탐 2장은 `conf=0.50`까지 올려도 그대로 2장(2건)이 유지되어, 신뢰도 0.50 이상의 고확신 오탐임을 알 수 있다.
- **추정 원인** *(로컬 환경에 `ultralytics`/`torch` 미설치로 개별 예측 박스를 영상별로 직접 대조하지 않았으므로, 스윕 통계와 `test` GT 분포 통계를 바탕으로 한 **추정 원인**으로 명시)*:
  1. **정상 오탐 2장 (추정 원인)**: 고신뢰도(≥0.50)로 판정된 비임플란트 체외/체내 금속 아티팩트, 진한 방사선 마커, 또는 뼈 중첩·석회화 구조가 나사·케이지 패턴과 유사하게 보였을 가능성이 높다.
  2. **임플란트 내부 FP 20건 및 FN 46건 (추정 원인)**: `test` 임플란트 58장 중 다중 박스 영상이 20장(34.5%), 대형 구조물 안에 소형 케이지가 중첩된 영상이 10장(내부 박스 19/96개)이므로, 좌·우 로드 병합 또는 개별 나사 분할 예측 시 `IoU < 0.50`으로 FP와 FN이 동시 발생했을 것으로 추정된다. 또한 면적 `0.5%` 미만 소형 GT가 21/96개(21.9%) 존재해 `imgsz=640` 축소 입력에서 소형 케이지 미검출이 FN 증가에 기여했을 것으로 추정된다.
