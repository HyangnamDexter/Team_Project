# 고밀도 이물질(금속·임플란트) 검출 방법 비교 실험 및 오검출 사례 정리

> **문서 목적**: 3주차 C 담당 2단계 실험 결과 기록. 동일한 VinDr-SpineXR `test` 122장(임플란트 58장, 정상 64장, 정답 박스 96개)을 기준으로 OpenCV 규칙 기반 방식(기본 / 국소 대비 / 개선 실험)과 YOLO11n 딥러닝 탐지 모델의 정량 성능·처리 속도·오검출(FP)/미검출(FN) 사례를 비교 정리한다.  
> ⚠️ 본 실험 결과는 교육 및 영상 품질 점검(고밀도 이물질 의심 영역 표시·재촬영 요청 보조) 목적이며 실제 의료 진단 용도가 아니다.

### 1.3 평가 지표 및 매칭 기준
1. **엄격 매칭 (`IoU ≥ 0.50`, 1:1 매칭)**: YOLO 공식 평가 기준과 동일. 예측 박스와 GT를 1:1 매칭하여 `IoU ≥ 0.50`만 `TP`로 인정.
2. **완화 매칭 (`IoU > 0`, 1:1 매칭 / 박스 중심 포함 1:1 매칭)**: OpenCV 연결 요소 검출은 임플란트 전체(나사+로드)를 개별 부품 조각으로 분할 검출하므로 `IoU ≥ 0.50` 달성이 구조적으로 어렵다. 따라서 "이물질 위치를 실제로 짚었는지" 확인하기 위해 `IoU > 0` 1:1 매칭과 예측 박스 중심이 GT 내부에 포함되는지(`Center-in-GT`, 1:1)를 함께 측정하였다.
3. **참고 지표 (`IoU > 0`, 다대일·파편 허용)**: 1개 GT 임플란트에 OpenCV 소형 박스 여러 개가 동시에 적중한 경우 중복 파편을 FP로 벌점 주지 않고 GT 적중률(`Recall`)과 GT 적중 예측 박스 비율(`Precision`)을 보조 산출하였다.
4. **처리 시간**: OpenCV는 순수 검출 알고리즘 실행 시간(`time.perf_counter`)만 측정하였다. (원본 DICOM 디스크 로딩·디코딩 평균 시간은 별도 `0.2303초/장` 소요)

### 2.3 정량 비교 핵심 해석
1. **OpenCV에서 `IoU ≥ 0.50` TP가 0~1건에 그친 구조적 원인**:
   - VinDr-SpineXR 정답 박스 96개 중 **63개(65.6%)가 영상 면적의 2%를 초과**하는 대형 조립체(나사+로드+추간 공간 전체) 단위 라벨이다.
   - 반면 `detect_foreign_objects`는 `max_area_ratio=0.02` 상한을 두고 밝은 금속 픽셀만 개별 연결 요소로 추출하므로, 임플란트 1개를 평균 **~13개의 소형 나사·봉 조각**(`bg_sigma=25.0`: GT 내부 적중 박스 1,098개 / 적중 GT 84개)으로 분할 검출한다. 그 결과 GT당 최대 IoU 중앙값이 `0.0135`(최대 `0.5011`)에 불과하다.
2. **국소 대비(`bg_sigma=25.0`)의 극적인 재현율 개선과 부작용**:
   - `IoU > 0` 기준 재현율(Recall)이 **45.83% → 86.46%** (`TP 44 → 83`, 다대일 `87.50%`)로 **+40.6%p 급상승**했다. 넓은 뼈 배경(골반·두개저)에 가려져 `base`가 놓친 임플란트 23장(39개 GT)을 구제했다.
   - 대신 척추체 종판(endplate), 늑골 교차부, 피질골 경계 등 날카로운 뼈 에지도 국소 피크로 강조되면서 전체 오검출이 `16.38 → 42.11 FP/img`로 2.57배 증가했다.
3. **가장자리 5% 마커 제외의 순수 오검출 절감 효과**:
   - `bg_sigma=25.0`에 상하좌우 5% 경계 필터를 추가하면 **GT 적중 박스 손실 0건(1,098 → 1,098, Recall 86.46% 유지)** 상태에서 오검출만 **894건(-17.4%)** 줄어들며, 정상 영상당 오검출이 `42.39 → 33.88`(**-20.1%**)로 개선되었다.
   - `MORPH_TOPHAT(51×51)` + 5% 경계 제외는 `bg_sigma=25.0` 대비 처리 속도가 **18% 빠르고**(0.1672초 vs 0.2042초) 총 FP도 18% 적지만(`3,485` vs `4,243`), 소형 금속 재현율이 다소 낮아(`82.29%` vs `86.46%`) 민감도 측면에서는 `bg_sigma=25.0 + 5% 경계 제외`가 우세했다.
4. **백분위(`percentile=99.5`) 방식의 근본 한계 (`normal FPR = 100%`) vs YOLO11n (`3.12%`)**:
   - OpenCV 백분위 방식은 **금속이 전혀 없는 정상 영상에서도 무조건 상위 0.5% 픽셀을 추출**하므로 정상 영상 64장 전체(100%)에서 오탐이 발생한다(`FP/normal = 14.88 ~ 42.39`).
   - 반면 **YOLO11n(`conf=0.30`)**은 형태·문맥을 학습하여 정상 영상 오탐률을 **3.12% (64장 중 2장)**, 전체 영상당 오검출을 **0.2459개**(OpenCV 개선 A 대비 **1/141 수준**)로 대폭 낮추면서 엄격 기준 `IoU ≥ 0.50`에서도 **F1 = 0.6596, mAP@0.5 = 0.6527**을 달성했다.

#### (2) 정상 영상 오탐(2장) 특징
- `conf=0.30` 기준 정상 64장 중 **단 2장(`normal_FPR = 3.12%`)**에서만 총 **3개의 FP 박스(`FP/normal = 0.0469`)**가 발생했다.
- `conf`를 `0.40`·`0.50`으로 높여도 `normal_FPR`이 그대로 `3.12% (2/64장)`, 정상 FP 박스 수가 `3건 → 2건`으로만 줄어든다. 즉, 정상 오탐 2장에는 **신뢰도 0.50 이상의 고확신(high-confidence) 금속 유사 구조물**(예: 비임플란트 체외/체내 금속 아티팩트, 진한 방사선 마커, 또는 뼈 중첩/석회화가 나사·케이지 패턴과 유사하게 보이는 경우)이 각 1개 이상 존재하며, 단순 threshold 상향만으로는 완전 제거가 어렵다.

#### (3) 임플란트 영상 내부 FP(27건) 및 FN(34건) 특징
- **FP의 90.0%(27/30건)가 임플란트 양성 영상 내부에서 발생**(`FP/implant = 0.4655` vs `FP/normal = 0.0469`, 약 10배 차이):
  1. **다중·중첩 GT 박스 경계 불일치 (`IoU < 0.50` 이중 벌점)**: `test` 임플란트 58장 중 **20장(34.5%)**이 다중 박스이고 **10장(19개 박스, 19.8%)**은 큰 구조물 박스 안에 소형 케이지 박스가 중첩되어 있다. 모델이 좌·우 로드를 1개로 묶어 예측하거나 반대로 개별 나사 단위로 쪼개 예측하면, 실제로 금속을 정확히 찾고도 `IoU < 0.50` 판정으로 **FP 1건과 FN 1건이 동시에 증가**한다.
  2. **초소형 케이지 마커 미검출 (`imgsz=640` 해상도 제약)**: `test` GT 96개 중 **21개(21.9%)가 면적 0.5% 미만**, **15개(15.6%)가 0.2% 미만**이다. 원본 `~2874×1243` 영상을 `640`으로 축소하면 초소형 케이지 핀은 약 `8~12 px` 수준으로 줄어들어 경량 백본(YOLO11n)에서 FN(34건)으로 이어지기 쉽다.
  3. **낮은 `conf`에서의 재현율 한계**: `conf=0.10`까지 낮춰도 `FN=23`(Recall 76.04%)이 남는 점에서, 소형 케이지·저대비 임플란트 개선을 위해서는 `imgsz=1024` 고해상도 학습이나 `yolo11s` 백본 확장이 효과적이다.

## 4. 종합 결론 및 서비스 적용 제언

1. **역할 분리(상호 보완적 활용)**:
   - **OpenCV (`detect_foreign_objects`)**: 별도 학습·GPU 없이 0.07~0.20초/장으로 원시 DICOM 픽셀에서 고밀도 영역과 중간 마스크(`threshold`, `cleaned`)를 투명하게 시각화할 수 있다. 특히 `bg_sigma=25.0`은 임플란트 위치 포착률(`IoU > 0` Recall **86.46%**)이 높으나, 백분위 방식의 구조적 특성상 **정상 영상 오탐률이 100%(33.88~42.39 FP/normal)**이므로 **자동 재촬영 알림(알람 트리거) 단독 기준으로 사용하기에는 부적합**하다.
   - **YOLO11n (`conf=0.30`)**: 정상 오탐률이 **3.12% (2/64장)**, 영상당 오검출이 **0.2459개**로 OpenCV 대비 오탐을 **99% 이상 절감**하면서도 엄격 `IoU ≥ 0.50`에서 `F1 = 0.6596`, `mAP@0.5 = 0.6527`을 달성해 **실제 이물질 의심 알림·재촬영 요청 보조 후보 검출기**로 적합하다.
2. **향후 개선 방향**:
   - **OpenCV 개선 시**: 상대 백분위(`np.percentile`)만으로는 정상 오탐 100% 문제를 해결할 수 없으므로, **절대 대비/Z-score 하한(예: 배경 대비 최소 SNR/표준편차 배수 조건)**을 결합하고, 5% 경계 필터와 더불어 문자 형태(L/R 마커) 제외 규칙을 검토해야 한다.
   - **YOLO 개선 시**: 초소형 케이지(면적 < 0.5%) FN을 줄이기 위해 `imgsz=1024` 고해상도 학습 및 `yolo11s` 모델 비교 실험을 권장하며, 임상 품질 점검(영상 단위 유무 판정) 관점에서는 박스 경계 분할 오차의 영향을 줄인 **영상 단위 이물질 유무 분류 지표**를 병행 보고하는 것이 바람직하다.
